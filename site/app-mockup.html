🎯 Goal

A simple task-tracker web app: add tasks, mark done, filter by status. Static, no backend.

✅ Requirements

1.1 User can add a task via an input + button.
1.2 User can toggle a task complete/incomplete.
1.3 User can filter: All / Active / Done.
1.4 Tasks persist in localStorage.

📐 Sections (build order)

S1 Layout + header
S2 Add-task form
S3 Task list + toggle
S4 Filters + persistence
