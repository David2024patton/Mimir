The problem

Today's AI coding tools have amnesia — and own you.

Every session starts from zero. Your corrections, preferences, and hard-won lessons vanish. And the good ones lock you into their models, their cloud, their pricing. Mímir is the answer: an agent that remembers everything and answers only to you.

Features

A complete agentic coding framework

🧠

The Cortex

A neural knowledge brain (neurons, synapses, engrams) on SurrealDB. Multi-modal knowledge + a self-learning memory with a forgetting curve and skill synthesis.

🔒

Sovereign & local-first

Bring any provider key or run 100% local (Ollama, llama.cpp, vLLM). Your keys, your data, your hardware. No vendor lock-in.

🛠️

Built-in deep tools

Terminal, filesystem, process control, in-memory code execution, and surgical edits — reimplemented natively, not bolted on.

🎯

Goal-driven autonomy

State the goal. Mímir makes a game plan, converts it to a to-do list, and works item-by-item — debug and test as it goes — until it's done.

🐢

Small-model friendly

Engineered so models ≤30B code smoothly: lean tools, focused context, step-by-step verification, and anti-derailment guardrails.

🛡️

Deterministic governance

A fail-closed policy gate, privilege rings, tamper-evident audit, and on-the-fly sandboxing. Misbehavior is structurally impossible.

📥

Ingest anything (Gjallarhorn)

Drop any file — web pages, PDFs, YouTube videos, audio, Office docs, images. Mímir converts it and files it into the Cortex. Plus built-in metasearch and scraping. Like NotebookLM, but unlimited and yours.

🖥️

Works everywhere

Desktop GUI, terminal, mobile over a secure tunnel, and chat channels (Discord, Slack, Telegram) — all against one home daemon.

🧩

One-click marketplace

Browse and one-click install MCP servers, skills, and personas from a curated marketplace — plus a typed plugin SDK and MCP support. Extend Mímir without forking it.

How it works

From "build me this" to done.

Bring your brain

Plug in any model API key, or point Mímir at a local model. One binary, any OS, no cloud required.

It plans, then builds

Mímir drafts a game plan, breaks it into a to-do list, and executes step-by-step — writing code, running the terminal, testing as it goes.

It remembers

Every correction, preference, and lesson becomes a memory. Next session — next project — it already knows.
